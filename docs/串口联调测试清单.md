# STM32 机械臂 · 串口联调测试清单

> 目标：验证下位机 UART 指令协议（帧解析、XOR 校验、软限位、状态机）全部符合预期。
> 完成一份勾选 → 这就是你下位机"工程化"的证据，可截图存档、写进简历。
> 版本：协议 v1　|　帧格式 `$CMD[,ARG]*CK<CR><LF>`，CK 为 `$` 与 `*` 之间字节的 XOR。

---

## 0. 准备（5 分钟）

| 项 | 值 |
|---|---|
| STM32 串口 | USART1，PA9=TX / PA10=RX |
| 串口助手 | 任意（XCOM / SSCOM / 串口猎人均可），115200 / 8 / N / 1，无校验 |
| 换行 | 勾选「发送新行」或帧尾手动加 `\r\n`（协议以 `\r` 或 `\n` 结尾成帧） |
| 接线 | USB 转 TTL：**TX↔RX、RX↔TX**，共地（GND 相连） |
| 上电顺序 | 先 PC 供电，再机械臂供电；舵机必须独立供电且共地 |
| 恢复手动 | 每轮测试前发出 `$MANUAL*1A` 确保进手动态 |

⚠️ 常见坑：USB 转 TTL 的 TX/RX 接反、波特率不对、没共地 → 收不到任何响应。

## 1. 基本指令（8 条，逐条测）

> 预期响应里 `*xx` 表示该校验值由板子自动计算，你实际收到的是正确值即可，不用核对其具体数字。
> 但 **PING 一定要看到 `$OK,PONG*xx`**，这是链路打通的标志。

| # | 发送 | 预期响应 | 通过 |
|---|------|----------|:---:|
| 1.1 | `$PING*10` | `$OK,PONG*xx`，且板子上应无动作 | ☐ |
| 1.2 | `$STATE*57` | `$OK,S,M,<6个当前脉宽>*xx`（初始 M=手动态） | ☐ |
| 1.3 | `$HOME*0F` | `$OK*xx`，六路平滑回中位 | ☐ |
| 1.4 | `$MOVE,0,1500*25` | `$OK*xx`，J1 平滑转至约 1500µs | ☐ |
| 1.5 | `$MOVE,3,1000*23` | `$OK*xx`，J4 转至约 1000µs | ☐ |
| 1.6 | `$JOINT,1500,1500,1500,1500,1500,1500*56` | `$OK*xx`，六路同到中位 | ☐ |
| 1.7 | `$STATE*57` 再发一次 | 状态变为 `C`（指令态），脉宽与上一步一致 | ☐ |
| 1.8 | `$MANUAL*1A` | `$OK*xx`，回到手动态，电位器可接管 | ☐ |

## 附：帧格式速查（写代码/做上位机时用）

```
请求: $CMD[,ARG1,ARG2...]*CK<CR><LF>
  CK = 对 "CMD[,ARG...]" 全部字节做 XOR，结果转 2 位大写十六进制
响应: $OK[,...数据]*CK<CR><LF>      成功
      $ERR,<code>*CK<CR><LF>        失败
        1=未知命令  2=校验失败  3=格式/参数错误  4=当前状态禁止
状态码: M=手动态  C=指令态  R=示教记录  P=示教回放  E=急停
```

上位机（OrangePi / Python）示例计算 CK：

```python
def ck(payload: str) -> str:
    v = 0
    for b in payload.encode("ascii"):
        v ^= b
    return f"{v:02X}"
```

## 7. 示教回放（S2）

> 目标：验证「手动示教 → 自动回放」全流程，以及轨迹管理、异常保护。
> 背景：记录态 `R`（电位器驱动 + 每 100ms 采样六路脉宽入 RAM），回放态 `P`（每 100ms 取点复现）。
> 前提：已通过第 1 节基本指令（尤其 1.2 `/1.8` 能进出手动态）。

### 7.1 功能主流程（必测）

| # | 操作 | 发送 | 预期响应/现象 | 通过 |
|---|------|------|---------------|:---:|
| 7.1.1 | 开始记录 | `$REC*54` | `$OK*xx` | ☐ |
| 7.1.2 | 确认状态 | `$STATE*57` | 状态字为 `R`，脉宽=当前实际值 | ☐ |
| 7.1.3 | 手动走位 | 拧电位器 J1~J6 走一段约 5~10 秒的动作 | 舵机平滑跟随电位器 | ☐ |
| 7.1.4 | 查询点数 | `$TNUM*02` | `$OK,<n>*xx`，n>0（约 = 演示秒数/0.1s·但≤600） | ☐ |
| 7.1.5 | 结束记录 | `$RECEND*1B` | `$OK,<n>*xx`，返回同一 n | ☐ |
| 7.1.6 | 确认回手动 | `$STATE*57` | 状态字变回 `M` | ☐ |
| 7.1.7 | 手动乱动再回 HOME | `$HOME*0F` | 舵机回中，制造"偏离轨迹"起点 | ☐ |
| 7.1.8 | 开始回放 | `$PLAY*04` | `$OK*xx`，状态字变 `P` | ☐ |
| 7.1.9 | 观察回放 | 不做任何操作 | 舵机从 7.1.7 的位置平滑复现 7.1.3 轨迹 | ☐ |
| 7.1.10 | 回放结束 | 自动 | 状态自动回 `M`（可用 `$STATE*57` 确认） | ☐ |

### 7.2 轨迹管理

| # | 操作 | 发送 | 预期响应/现象 | 通过 |
|---|------|------|---------------|:---:|
| 7.2.1 | 空轨迹回放 | （复位后不录直接）`$PLAY*04` | `$ERR,3`（无轨迹可播） | ☐ |
| 7.2.2 | 查询空轨迹 | `$TNUM*02` | `$OK,0*xx` | ☐ |
| 7.2.3 | 清空 | 记录 2 秒后 `$MANUAL*1A` → `$CLEAR*59` | `$OK*xx` | ☐ |
| 7.2.4 | 清空后查询 | `$TNUM*02` | `$OK,0*xx` | ☐ |
| 7.2.5 | 重复性 | 同一段动作连续录/放两次 | 两次轨迹终点脉宽差≤30µs（可用 `$STATE*57` 对比） | ☐ |

### 7.3 异常与保护（重点安全项）

| # | 操作 | 发送 | 预期响应/现象 | 通过 |
|---|------|------|---------------|:---:|
| 7.3.1 | 记录中发 MOVE | `$REC*54` 后 `$MOVE,0,1500*25` | `$OK*xx`；`$STATE*57` 显示状态变 `C`，**记录自动停止** | ☐ |
| 7.3.2 | 回放中发 STOP | `$PLAY*04` 后 `$STOP*18` | `$OK*xx`；`$STATE*57` 显示 `E`，输出冻结，**回放自动停止** | ☐ |
| 7.3.3 | 急停解后回手动 | `$RESUME*19` | `$OK*xx`，状态回 `M`，电位器接管，无残留轨迹乱动 | ☐ |
| 7.3.4 | 记录中清空 | `$REC*54` 后 `$CLEAR*59` | `$ERR,4`（记录中禁止清空） | ☐ |
| 7.3.5 | 回放中清空 | `$REC`...`$RECEND`...`$PLAY*04` 后 `$CLEAR*59` | `$ERR,4`（回放中禁止清空） | ☐ |
| 7.3.6 | 缓冲上限 | 连续记录 >60 秒 | 到达 600 点后 `$STATE*57` 自动回 `M`，`$TNUM*02`=600 | ☐ |

> 设计说明（面试点）：7.3.1/7.3.2 展示「示教模块与状态机解耦」——任何外部接管（MOVE/急停）都会让 `Teach_Tick` 自动退出，防止残留半截轨迹继续乱动；7.2.5 的重复性检验「时间轴一致回放」的稳定性。

## 8. 周期遥测开关（LOG）

> 目标：验证下位机周期打印（每 3 秒一条 `STATE | PULSE ...`）可由命令开关，不再一直刷屏。
> 背景：板子上电默认**关闭**周期打印，接收区只在每次命令应答时返回数据；需要观察实时脉宽时再 `$LOG,1` 打开。

| # | 操作 | 发送 | 预期响应/现象 | 通过 |
|---|------|------|---------------|:---:|
| 8.1 | 上电初始态 | 复位后等待 >5 秒 | 接收区**无**周期 `STATE` 刷屏（默认关闭） | ☐ |
| 8.2 | 开启遥测 | `$LOG,1*59` | `$OK*xx`；约 3 秒后开始每条 `STATE 0 \| PULSE ...` | ☐ |
| 8.3 | 确认持续输出 | 等待 10 秒 | 持续每 ~3 秒刷一条，脉宽随电位器变化 | ☐ |
| 8.4 | 关闭遥测 | `$LOG,0*58` | `$OK*xx`；约 3 秒内停止刷屏 | ☐ |
| 8.5 | 关闭后确认 | 等待 >5 秒 | 接收区**不再**出现 `STATE`，仅剩命令应答 | ☐ |
| 8.6 | 命令应答不受影响 | 关闭态发 `$PING*10` | 仍正常返回 `$OK,PONG*xx` | ☐ |
| 8.7 | 参数越界 | `$LOG,2*5A` | `$ERR,3*xx`（LOG 只接受 0/1） | ☐ |
| 8.8 | 缺参数 | `$LOG*44` | `$ERR,3*xx`（缺参数） | ☐ |

> 设计说明（面试点）：8.1/8.5 验证"默认关闭、命令控制"——避免周期打印淹没命令-应答，是嵌入式串口调试的良好抽象；8.7/8.8 与第 4 节一致，确保新命令同样走严格参数校验。
