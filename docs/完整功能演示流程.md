# 六自由度机械臂视觉抓取系统 —— 全功能演示流程

> 适用场景：项目验收/比赛现场演示。
> 本文按"演示前准备 → 逐项功能 → 演示编排 → 故障快速恢复"组织，每个功能给出可直接照做的步骤。

---

## 一、演示前准备（约 10 分钟）

### 1.1 硬件接线核对

| 模块 | 接口 | 接线要点 |
| --- | --- | --- |
| USB-TTL 上位机 | USART1（PA9/PA10） | USB-TTL.TX→PA10，USB-TTL.RX→PA9，GND→GND |
| 蓝牙 HC-05 | USART2（PD5/PD6） | TXD→PD6，RXD→PD5（建议串 1kΩ），独立稳压 5V 供电并共地 |
| WiFi ESP-01S | USART3（PB10/PB11） | TXD→PB11，RXD→PB10，3.3V 供电 |
| RFID RC522 | 软件 SPI（PB12~PB15，PB0=RST） | 3.3V + GND 共地，天线区朝上 |
| 电位器 ×6 | ADC1 IN0~IN5（PA0~PA5） | 3.3V 供电，10kΩ 电位器 |
| 舵机驱动 | PCA9685（I2C1：PB6/PB7） | 舵机接 J1~J6，上电前确认限位 |
| USB 摄像头 | PC 端 | 眼在外固定安装（相机不随臂动），正对工作区，挂高覆盖 250×200mm |

### 1.2 固件与软件确认

1. Keil 打开 `MDK-ARM/Robotic arm vision.uvprojx`，编译下载（无错误即可）。
2. 电脑插入 USB-TTL，打开"设备管理器 → 端口"记下 COM 号（示例用 COM7）。
3. 确认 Python 依赖已装：`pip install pyserial matplotlib opencv-python numpy`。
4. 确认 `vision/config.json` 的 `base_x/base_y/roi/min_area` 是最近一次标定的值。

### 1.3 上电自检（必做）

打开任意串口助手（或直接跑上位机）观察开机信息，应依次出现：

```
RC522 version: 0x82
RC522 RFID init OK
Robot arm ready. Hold HOME (idle, wait CMD).
Protocol: $CMD*ck\r\n (PING/STATE/HOME/STOP/RESUME/MANUAL/MOVE/JOINT/REC/RECEND/PLAY/TNUM/CLEAR)
```

出现 `Robot arm ready` 即固件正常，机械臂默认停在 HOME 位、处于 CMD 待命态。`0x82` 为国产兼容芯片的正常版本号，`0x00/0xFF` 说明 RFID 失联（见故障表）。

## 二、功能 1：PC 串口上位机控制（arm_host.py）

展示点：统一指令协议、XOR 校验、状态查询、单轴控制、六轴同步、示教回放、轨迹对比。

### 2.1 启动

```powershell
cd tools
python arm_host.py COM7
```

连接成功会先自动 PING 一次，随后出现 17 项菜单。

### 2.2 逐项演示顺序

| 操作 | 预期现象 | 讲解词要点 |
| --- | --- | --- |
| 菜单 `1` PING | 回 `OK,PONG` | 链路测试，证明协议通 |
| 菜单 `2` STATE | 回状态 + 六路脉宽 | 状态机字符：C=CMD、M=MANUAL、P=PLAYBACK |
| 菜单 `3` HOME | 回 `OK`，臂回 HOME | 中位表来自实测标定 |
| 菜单 `7` MOVE 输入 `0,1800` | J1 转到 1800 | 单轴微调，带软限位保护 |
| 菜单 `7` MOVE 输入 `5,1500` | 夹爪半开 | J6=夹爪，通道 0~5 对应 J1~J6 |
| 菜单 `8` JOINT 输入 6 个脉宽 | 六轴同时到位 | 六轴同步指令 |
| 菜单 `9` REC | 开始示教记录 | 接下来手动 J1 摆动几下 |
| 菜单 `10` RECEND | 回 `OK,点数` | 记录结束，返回采样点数 |
| 菜单 `11` PLAY | 机械臂自动回放刚才动作 | 示教-回放闭环 |
| 菜单 `12` TNUM | 回轨迹点数 | 与 RECEND 点数一致 |
| 菜单 `13` CLEAR | 清空轨迹 | 收尾用 |
| 菜单 `15` 一键示教回放 | 自动 记录→回放→弹对比图 | 展示 6 路脉宽曲线与原/回放误差统计 |
| 菜单 `16` SCAN姿态 | 臂移到扫描姿态 | 眼在手方案的拍摄姿态 |
| 菜单 `17` SCAN保存 | 提示已写入 config.json | 需先摆好姿态再保存（见功能 6） |

演示话术：所有指令都是 `$命令,参数*校验码\r\n`，校验码为 XOR 自动计算，三路串口共用同一套协议，响应自动回发到命令来源通道。

## 三、功能 2：蓝牙 HC-05 无线控制

展示点：经典蓝牙 SPP 透传，手机直接控制机械臂。

### 3.1 演示步骤

1. 确认 HC-05 已 AT 配置：波特率 115200、名称 `ARM-BT`、密码 `1234`（未配置可按住 EN/KEY 上电进 AT 模式，发送 `AT+UART=115200,0,0`、`AT+NAME=ARM-BT`、`AT+PSWD=1234`，然后断电重插进入透传模式）。
2. 手机打开系统蓝牙，配对 `ARM-BT`（密码 1234）。
3. 打开"蓝牙串口"类 APP（如 Serial Bluetooth Terminal），连接 ARM-BT。
4. 依次发送（校验码已算好，直接复制）：

```
$MOVE,0,1800*28    → J1 转到 1800
$MOVE,0,1300*23    → J1 转到 1300
$HOME*0F           → 回 HOME
$MOVE,5,900*1D     → 夹爪张开（J6 通道 5）
$MOVE,5,1900*2C    → 夹爪闭合（1900，减小夹持力度）
```

5. 观察机械臂随手机命令动作，串口助手同步看到响应。

注意：HC-05 必须独立稳压供电并共地，从 STM32 引脚取电会因建链电流不足反复掉线。

## 四、功能 3：WiFi ESP-01S 远程控制

展示点：ESP8266 的 UART↔WiFi 桥接，PC/手机作为 TCP 客户端远程控制。

### 4.1 启动

ESP-01S 上电后由固件自动配置热点（SSID/密码在 `Core/Src/wifi.c` 的 `WIFI_AP_SSID`/`WIFI_AP_PASS` 中改成你自己的值，TCP 端口 9000），PC 或手机连上该热点即可。

### 4.2 三种控制方式

方式 A（上位机走 TCP，与串口完全同一套操作）：

```powershell
python arm_host.py --wifi 192.168.4.1:9000
```

方式 B（网页实时控制，滑块拖拽）：

```powershell
cd tools
python web_control.py --wifi 192.168.4.1:9000
# 浏览器打开脚本提示的地址，拖动 6 路滑块实时控制，页面每秒轮询状态
```

方式 C（手机 TCP 客户端）：手机连自建热点，装 TCP 客户端（如 "TCP Client" 工具），服务器地址 `192.168.4.1`、端口 `9000`，发送同样的 `$HOME*0F` 等指令帧。

### 4.3 演示话术

突出两点：① 指令协议与串口/蓝牙完全一致，换通道不换协议；② ESP-01S 只做 UART↔WiFi 透明桥接，数据格式由 STM32 协议栈统一处理。

## 五、功能 4：RFID 刷卡切换模式

展示点：RC522 读卡、双卡切换 MANUAL/HOME 模式、失联自动恢复。

### 5.1 演示步骤

1. 上电后状态为 CMD 待命。
2. 钥匙扣（UID 9A 7C 73 8E）贴近天线区，串口打印 `RFID: -> MANUAL`，进入手动模式——此时 MOVE/HOME 等指令被拒绝，电位器接管。
3. 转动任意电位器，对应关节实时跟随（见功能 5）。
4. 卡片（UID 5B 0B DE 53）贴近天线区，串口打印 `RFID: -> HOME`，退回 CMD 待命并回 HOME。

### 5.2 演示话术

刷卡切换对应"刷卡授权/模式门禁"的工程场景；模块失联（Ver=00）时固件会自动执行硬件复位 + 软复位恢复，无需重启。

## 六、功能 5：电位器手动控制（MANUAL 模式）

展示点：ADC 采样（ADC1 IN0~IN5）、六路电位器实时跟随。

### 6.1 演示步骤

1. 通过任意方式进入 MANUAL：刷卡（钥匙扣）或上位机菜单 `6` MANUAL。
2. 依次拨动 J1~J6 对应电位器，观察六个关节平滑跟随，脉宽在软限位内。
3. 演示完用卡片刷回（或上位机 `3` HOME / `5` RESUME）退出手动。

说明：电位器 0~3.3V 经 ADC 按各轴实测 `SERVO_Jx_MIN~SERVO_Jx_MAX` 线性映射为脉宽（J1 800~2300us、J3/J4 520~2500us、J5 500~2500us、J6 900~2100us），限位与中位全部使用实测标定值。

## 七、功能 6：视觉自动抓取（grasp.py）

展示点：目标识别（HSV）、像素→毫米（Homography）、逆运动学解算、夹爪方向自适应（沿边）、远目标前倾扩臂。

### 7.1 演示前标定（相机固定、不随臂动，即"眼在外"：标定与抓取共用同一固定视角）

步骤 1：四点桌面标定

```powershell
cd vision
python homography.py --source 0 --mode points --width 250 --height 200 --out homography.json
```

标定规则：①世界原点任意位置；②沿真机正右量 250mm；③对角点；④沿真机正前量 200mm。完成后把①点的机械臂坐标量出，填入 `config.json` 的 `base_x/base_y`。

步骤 2：更新 ROI 像素框（工作区 250×200mm）

```powershell
python set_roi.py --homography homography.json --width 250 --height 200
```

眼在手方案才需要额外的"扫描姿态 + --scan"（当前未启用），眼在外无需此步骤。

### 7.2 启动抓取

```powershell
python grasp.py --source 0 --homography homography.json --port COM7 --grip-conv 90 --off-x 1.5 --off-y 1.0
```

启动后选择运行模式（回车=模式 1）：

| 模式 | 用途 |
| --- | --- |
| 1 逐步抓取 | 每一步按空格，适合边讲边演示 |
| 2 自动连续 | 快照画面目标后自动依次抓取+放物 |
| 3 只抓指定颜色 | 输入颜色名，只抓该色 |
| 4 鼠标点击 | 左键点目标自动抓取；抓完左键点工作区选投放点 |

### 7.3 模式 1 的按键节奏（重点演示）

| 按键 | 动作 | 讲解词 |
| --- | --- | --- |
| 空格（第 1 次） | 选目标并到准备位 | 目标上方安全高度 |
| 空格（第 2 次） | 下降 | 贴近目标 |
| 空格（第 3 次） | 闭合夹爪 | 抓取 |
| 空格（第 4 次） | 抬起 | 离开桌面 |
| 空格（第 5 次） | 放物：降到位→张开→抬起 | 码放 |
| 空格（第 6 次） | 选下一个目标 | 循环 |

辅助按键：`h` 回 HOME；`c` 切换颜色过滤；`r` 返回模式菜单；`q` 退出；`[` `]` 实时微调 J5 腕偏移（绿线=夹爪张开方向，红线=目标长边方向，二者应垂直），按 `s` 保存到 config.json。

### 7.4 模式 4：鼠标点击模式（演示亮点，适合互动）

选模式 4 后，画面窗口直接响应鼠标：

| 操作 | 效果 | 画面反馈 |
| --- | --- | --- |
| 左键点击目标 | 自动连续抓取（准备→下降→闭合→抬起） | 目标上出现红色圆圈 |
| 抓取完成后左键点击工作区任意点 | 把物体放到该点（降到位→张开→抬起，自动前倾扩臂） | 投放点出现蓝色圆圈 |
| 左键点击空白处（无目标） | 忽略并提示"点击处没有目标" | 终端提示 |
| 投放点不可达 | 提示并保持待放物，可换点再点 | 终端提示 |

要点：
- 点目标时自动选"离点击处最近的目标"（100px 内），沿边/前倾逻辑与模式 1 完全相同。
- 点击投放点不受颜色过滤影响，工作区任意可达位置都能放。
- 演示建议：先点红色方块 → 机械臂自动抓取 → 再点画面右下角空白区 → 精确放到点击处，现场互动感强。

### 7.5 演示看点

1. 放置一个方块/长方形目标，观察 J5 自动旋转夹爪沿长边夹取（绿线垂直红线）。
2. 放置圆形目标，夹爪保持默认方向。
3. 远目标放远一点，观察机械臂前倾角自动 +5°（上限 45°）扩臂抓取。
4. 画面里黄色虚线框为 ROI 工作区，只识别框内目标。

## 八、功能 7：多通道联调一键演示（demo.py）

展示点：串口/蓝牙/WiFi 三通道串起一遍完整剧本，适合收尾时快速展示"多通道并存"。

```powershell
cd tools
python demo.py --port COM7
```

自动执行剧本：

1. PING 链路测试
2. 回 HOME
3. J1 摆动（1800→1300→1550）
4. J6 夹爪开合（闭合→张开→半开）
5. J5 腕旋转
6. 回 HOME
7. 提示用手机蓝牙发 `$MOVE,0,1800*28` / `$MOVE,0,1300*23` / `$HOME*0F`，按回车继续
8. 自动另开 TCP 连接 192.168.4.1:9000 验证 WiFi 通道（J6 开合 + HOME）
9. 回 HOME 收尾

若 WiFi 未接，脚本会提示跳过本步，不影响其他模块结论。

## 九、功能 8：急停与恢复

展示点：状态机保护逻辑。

上位机菜单 `4` STOP → 机械臂冻结，处于 ESTOP/冻结态；菜单 `5` RESUME 解除冻结；`3` HOME 复位。可现场演示"运动中急停"：先 JOINT 动起来，立刻 STOP，机械臂停在原地。

## 十一、现场故障快速恢复表

| 现象 | 快速处理 |
| --- | --- |
| 串口打不开 | 设备管理器核对 COM 号；拔插 USB-TTL 后重开脚本 |
| PING 无响应 | 检查 USB-TTL TX/RX 是否接反；按复位键重上电 |
| 机械臂不动但 PING 正常 | 查状态机：若 M=MANUAL 需刷卡/上位机切回 CMD；若 E=ESTOP 先 RESUME |
| 刷卡无反应 | 看开机 Ver：0x82 正常；0x00 则检查 3.3V/GND/RST 接线，必要时换模块 |
| 刷卡提示但模式没切 | 确认用对卡：钥匙扣→MANUAL，卡片→HOME |
| 蓝牙连上即断 | 独立稳压供电 + 共地；重新配对 ARM-BT/1234 |
| WiFi 连不上 | 确认手机连的是自建热点；TCP 客户端选"TCP Client"模式，端口 9000 |
| 视觉识别乱跳 | 减少反光、调光照；检查 ROI 是否盖住工作区；min_area 保持 200~300 |
| 抓取位置偏移 | 检查 base_x/base_y 是否与当前①原点一致；相机固定后不要挪动 |
| 夹爪方向偏 90° | 键盘 `[`/`]` 微调 wrist-offset 后按 `s` 保存 |
| 目标超出臂展 | 确认前倾自动扩臂生效（--tilt-max 默认 45°）；目标放回工作区中部 |

## 十二、演示前 5 分钟终检清单

1. 固件已烧录最新版，上电自检三行日志完整。
2. `vision/config.json`：base_x/base_y/roi/min_area 为最近标定值。
3. 摄像头固定不动，画面清晰、工作区完整可见。
4. 两个 RFID 卡带齐（钥匙扣 + 卡片），确认对应模式。
5. 手机已配对 ARM-BT、已装蓝牙串口 APP；TCP 客户端工具已装。
6. 电位器供电 3.3V 正常，MANUAL 下六路可跟随。
7. 备用：USB 延长线、网口/充电宝给 ESP-01S 与 HC-05 独立供电。
